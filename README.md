# 416MES 仓储管理系统（单机离线版）

单文件网页应用：`index.html` 双击即用，无需安装、无需联网。适配汉印 N41 热敏打印机 + 60×40mm 三防标签纸。

> 注意：「排版工具」页签依赖 `typesetting/` 文件夹和 `nec-gallery.js`（NEC 图库清单），拷贝本系统时请一起复制。

## 快速开始

1. 门户首页 `home.html`（双击或访问 http://localhost:8000/home.html ）：五个模块入口 + InvenTree 集成入口 + 在线状态自检
2. 作业端 `index.html` 双击即用，无需安装、无需联网。适配汉印 N41 热敏打印机 + 60×40mm 三防标签纸
2. 首次打开自动载入种子数据：64 个货架库位码（B区 2货架×4层×8位）+ 12 个工位格码 + 40 个容器码 + 2 条示例物料
3. 「标签打印」页勾选 → 预览 → 打印（纸张可选 **60×40 标签纸** 或 **A4 整版** 3×7=21 张/页；色彩可选 **高对比纯黑 / 彩色主视觉**；属性文字 **自动占满空白**（8.5–18pt 自适应），编码自动填满左栏，字号 70%–120% 可微调）
4. 定期点「导出备份 JSON」（全量含流水）或「导出 Excel 台账」备份（数据存在浏览器 localStorage，换浏览器/清缓存会丢）

## 人员台账（v3 新增）

「人员台账」页维护社团成员名录：编号（MB-xxx 自动生成不可改）、姓名、学号、部门/SIG、职务、电话、备注。姓名自动同步到右上角「操作人」下拉与 NEC 工单「负责人」候选；支持搜索、增删行、Excel「人员」sheet 导出导入、JSON 备份合并。

### 双向同步闭环（feishu-sync.mjs）

```bash
node feishu-sync.mjs status                        # 连通性 + 各表记录数
node feishu-sync.mjs push 416MES_备份_xxx.json     # 本地备份 → 飞书（按编码 upsert：已存在更新、不存在新建，幂等）
node feishu-sync.mjs pull [输出.json]              # 飞书 → 本地备份 JSON（网页端「导入合并」回本机）
```

- **上云**：网页端「导出备份 JSON」→ `push` —— 8 张表全量按业务键（物料码/库位码/容器码/编号/物品码/手册码/工单号/流水号）去重，重复推送不产生重复记录
- **回本**：`pull` 生成与网页端「导入合并」完全兼容的备份 JSON（select 单选 / datetime 时区 / 明细串均已按本地格式归一化），合并按编码去重、流水取最大序号
- 库存流水只增不改：无 seq 的旧数据跳过不推，云端流水号 `#000123` 幂等
- 已验证完整往返：导出 → push → pull → 导入合并，日期/时间戳/余量逐字节一致

## 七类标签规范（NEC26 主视觉版）

所有标签统一遵循 NEC26「BUILT TO DAWN」主视觉：顶部海军蓝渐变条（#0E1A55→#172A88）+ 白色 NEC Logo + 类型色块 + 青色 #00B0F0 光线；底部海军蓝标语条「BUILT TO DAWN · KEEP BUILDING▓ / newenergycoder.club」。Logo 已内嵌 index.html（base64），离线可打印；源文件 `nec-logo.png` / `nec-logo-white.png` 提取自主视觉 pptx。打印时自动强化：纯黑条（热敏最大对比度）+ `print-color-adjust:exact`（忘开“背景图形”也能打出黑条）+ 编码字号自动填满左栏（9–14pt 自适应）。

| 类型 | 色块 | 人读编码 | 二维码机读串 | 版面 |
|---|---|---|---|---|
| 库位码 | 蓝 | `B-01-03-04`（区域-货架-层-位）/ `W01-G02`（工位-格） | `LOC:B-01-03-04` | 左上大字号编码 |
| 容器码 | 绿 | `A4SH-015` / `SLG-028` / `XK-036` / `ZZX-102` | `CTN:A4SH-015` | 左上大字号编码 |
| 物料码 | 黄 | `GJ-SD-001`（大类-中类-流水） | `MAT:GJ-SD-001` | 左下 22mm 二维码 |
| 物品码 | 青 | `WP-001`（3位流水，设备/工具等耐用品） | `ITM:WP-001` | 右侧名称/规格/库位 |
| 手册码 | 玫红 | `SC-001`（3位流水，资料册/手册） | `MAN:SC-001` | 右侧名称/版本/库位 |
| 工单码 | 红 | `LL20260909007`（类型+日期+3位流水） | `WIP:LL20260909007` | 紧凑模式：编码10.5pt+19mm 二维码，右侧属性+打印日期 |
| NEC工单 | 紫 | `RW20260909003`（类型+日期+3位流水） | `NEC:RW20260909003` | 同上，右侧含标题/负责人 |

工单类型：**LL 领料 / BH 补货 / JH 拣货 / TL 退料**，流水号按「类型+日期」自动递增。

容器类型缩写：A4SH=A4四抽收纳盒，SLG=三连格文件盒（牛皮色 28×28×20cm 中距9cm），XK=斜口零件盒，ZZX=6040周转箱，SC4=四层四格牛皮纸收纳盒（32×25×34cm），KF=开放式收纳格（32×25×6cm，含12×6×6小格×4）。

C区角钢货架（150×30×200cm 四层 ×6 架）已**内置进系统**：打开页面自动入库 106 库位 + 82 容器（缺则补，不覆盖已有改动），无需手动导入。层号从上往下编（第 1 层=顶层，第 4 层=最底层预留位，共 24 位）；1-2 号架上三层全放四层四格（SC4-001~024）；3 号架顶层放三连格、L2-L3 放 SC4-025~030（L2 余 2 位放 KF 两摞 KF-001~004）；4-6 号架上三层全放三连格（SLG-011~058）。

一键打印：「标签打印」页 → 筛选框输 `C-`（库位）或 `SC4/SLG-/KF`（容器）→「全选(筛选结果)」→ 打印，只出 C 区标签，不带 B 区老标签。（根目录 `布局导入_C区角钢货架.json` 保留作跨设备导入备用）

## 模块区大卡（A4 整页，NEC 主视觉）

模块区是正式主数据（与库位码同台账、随 Excel 导出/导入、可删可增）：内置 M-01 连接器 / M-02 电机 / M-03 电池 / M-04 防护设备 / M-05 端子线材。新增：「编码生成」页填名称点「生成模块区」自动编 M-xx；删除：「标签打印 → 模块区卡」勾选后「从台账删除勾选」。打印：类型条选 **模块区卡**（自动切 A4 模式）→ 全选 → 打印，每页一张大卡（Just Scan QR 风格，机读串 `LOC:M-0x`，扫码页直接识读）。

物料大类建议：GJ 工具、HC 耗材、PJ 配件、DZ 电子件——中类自定，流水 3 位。

## 打印操作（汉印 N41）

1. 装 60×40mm 三防热敏纸，用驱动自带工具校准纸张
2. 在「标签打印」页勾选记录，点「🖨 打印勾选标签」
3. 打印对话框：**纸张 60×40mm（自定义）、边距=无、缩放=100%、取消页眉页脚、背景图形=开**（色条需要）
4. 二维码内容=带前缀机读串，手机/扫码枪均可扫

## 扫码出入库闭环（规则 5）

在「扫码出入库」页用扫码枪或手输，回车确认：

- `MAT:GJ-SD-001` → 查物料库存/位置
- `LOC:B-01-03-04` / `CTN:XK-001` → 查该位置存放什么
- `WIP:LL20260909007` → 打开领料工单，确认数量后「确认执行」**扣减**库存
- `WIP:BH…` / `WIP:TL…` → 执行后**增加**库存；库存不足或未建档会拦截
- 工单执行一次后闭环，不可重复执行；**没有扫码动作，库存数就不变**

## 维护规则

1. **编码不变，属性可变**：改名/换规格/调货位只改台账字段，编码永不重打；标签只在物理载体报废时作废
2. **台账即主数据**：「导出 Excel」得到 4 个 sheet（物料台账/库位/容器/工单记录），可直接导入飞书多维表格，也可编辑后「导入 Excel」回系统
3. **空位提前批量打印**：「编码生成」页按货架/层/位参数一键补齐，贴上即启用
4. **打印登记**：每张标签右下角自动带打印日期；三防纸正常用 2 年以上，褪色即重打，扫码核对编码一致
5. **工单闭环**：工单打印随货走，扫 `WIP:` 码执行才动库存

## NEC 小工单（社团轻量工单 + 飞书同步）

面向 New Energy Coder 社团的任务级工单，与仓储工单相互独立。

- **页签「NEC小工单」**：新建（标题/类型/负责人/优先级/截止/关联物料/备注）→ 列表改状态（待处理→进行中→已完成/已取消）→ 勾选后在「标签打印」打**紫色 NEC 工单标签**（二维码机读串 `NEC:编码`）
- **编码**：类型+日期+3位流水，例 `RW20260909003`；类型：RW 任务 / LL 领料 / CG 采购 / WX 维修 / HD 活动 / QT 其他
- **随 Excel 台账一起导出/导入**（sheet「NEC工单」）

### 同步到飞书（lark-cli）

```bash
# 首次：创建多维表格「NEC小工单台账」+ 选择通知群，生成 nec-sync.config.json
node nec-sync.mjs init

# 日常：网页点「导出同步文件」得到 nec-wip-export.json，放到本目录后
node nec-sync.mjs push              # 判重后新建/更新记录，新建和状态变更发群通知
node nec-sync.mjs push --dry-run    # 只打印计划，不实际执行
node nec-sync.mjs status            # 查看配置与连通性
```

- 判重规则：按「工单号」精确搜索，已存在且字段有变才更新，无变化跳过
- 群通知：markdown 卡片，含工单号/标题/类型/负责人/状态；`--idempotency-key` 防重发
- 配置文件不含密钥；lark-cli 凭证由 `lark-cli config` 统一管理

## 排版工具（海报/看板/贴纸设计）

「排版工具」页签内嵌 Zonlin 自动排版工具 1.5（`typesetting/` 目录），适合做仓库看板、货架区域海报、贴纸等。

- **数据桥**：顶部选类型+记录 → 「📋 复制排版文本」（名称/规格/编码已按行排好）→ 到画板 Text 框粘贴；「⬇ 下载二维码 PNG」生成带前缀机读串的二维码（218×218），在排版工具里「添加图片」导入
- 「↗ 新标签页打开」可获得完整大屏体验；排版结果由排版工具导出 PNG/JPEG/SVG（A4/A3 已按 300 PPI 预设）
- ⚠️ 分发本系统时必须连同 `typesetting/` 文件夹一起拷贝（内含字体），不能只发 index.html
- 详细用法见 `typesetting/使用教程1.5.txt`

### NEC 图库（官网 gallery 图片直选）

「排版工具」页签内置 NEC 官网图库面板（`nec-gallery.js` 清单，5 个专辑 / 752 张 ROBOCON 赛场图）：

- 选专辑 → 缩略图网格浏览（每次 48 张，可「加载更多」）→ 点击图片下载 → 排版工具「添加图片」导入画板

## 技术说明

- 单文件离线：内嵌 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT）与 [SheetJS](https://sheetjs.com/)，无网络依赖
- 数据：浏览器 localStorage（键 `mes416_state_v1`）+ Excel 导入导出
- 修改源码：**直接编辑 `index.html`**（本项目已由多个功能迭代直接在 index.html 上演进，以 git 历史为准）。`.build/` 下的 part1.html/app.js 为初始版本的历史源码快照，⚠️ 不要再用 cat 重拼生成 index.html，否则会覆盖后续功能（人员台账、C区布局、排版工具等）。排版工具源码在 `typesetting/` 目录单独维护。

Auto-Typesetting tools1.5 - 使用教程

一、打开和分享
1. 双击打开“Auto-Typesetting tools1.5.html”，电脑端建议使用最新版 Chrome 或 Edge。
2. 请勿只发送 HTML 文件。分享或复制到其他电脑时，应发送整个“Auto-Typesetting tools1.5”文件夹，并保留其中的 fonts 字体文件夹，否则默认字体可能无法正常显示。
3. 手机和 iPad 可使用网页端：https://zonlinjiang-code.github.io/auto-typesetting-tools/

二、最快开始
1. 在左侧 Text 文本框输入文字，需要换行时按 Enter。
2. 点击“设置背景”导入主背景图；如需加入其他图片，点击“添加图片”，可一次选择一张或多张图片。
3. 调整字体、字号、颜色、间距、行距、阴影、描边或文字背景。
4. 使用画板底部的 W、H 或尺寸预设设置画面大小。
5. 完成排版后，在 Export 导出面板选择 JPEG、PNG 或 SVG。

三、画板底部工具
1. “↖”是选择工具，也可按 V 切换。它用于选择、框选、移动和缩放文字或图片。
2. “T”是文字工具，也可按 T 切换。点击画板可创建文字，拖动可创建区域文字框。
3. W 和 H 分别是画板宽度和高度，输入数值后按 Enter 即可应用。
4. 尺寸菜单提供自定义、16:9、1:1、4:3、9:16、3:4，以及打印用 A4、A3。
5. A4 为 2480 × 3508 px，A3 为 3508 × 4961 px，均按 300 PPI 设置。专业印刷所需的出血、色彩模式等要求请另行向印刷方确认。
6. “− / 适合 / ＋”只调整画板查看倍率，不会改变最终导出尺寸。点击“适合”可让整个画板自动适应窗口。
7. 鼠标位于画板查看区域时，也可以按住 Ctrl（Mac 为 Command）滚动滚轮缩放画板。
8. 太阳或月亮按钮用于切换亮色、深色工作区，画板内容和导出结果不会改变。
9. 1.5 默认保持当前排版关系；切换画板尺寸时，文字和图片会按新画板自动适配，无需再打开“保持排版”开关。

四、文字排版与选择
1. 默认排版模式适合快速生成版式，可通过九宫格快速决定文字在画面中的位置。
2. 点击 FREE，或使用“↖”选择工具点击画板文字，即可进入自由排版状态。
3. 拖动画板空白区域可框选多个文字对象；按住 Shift、Ctrl 或 Command 点击可增减选择。
4. 选择文字后，可使用“智能、按行、逐字”决定对齐时如何识别对象。
5. 选择两个或以上对象时，“选区”对齐可让它们互相左对齐、水平居中、右对齐、顶对齐、垂直居中或底对齐。
6. 只选择一个对象时，将对齐基准切换为“画布”，即可对齐到画板边缘或画板中心。
7. 选中多个文字对象后，可按 Ctrl/Command + G 组合；按 Ctrl/Command + Shift + G 取消组合。
8. 文字锁开启时，文字不能移动、缩放、旋转、删除或对齐，可再次点击锁按钮解锁。

五、区域文字框
1. 框选一组自由文字后，点击“构建区域文字”，可将其合并为一个区域文字框。
2. 区域文字框可整体移动、缩放和旋转，不会再拆散为单个字符。
3. 点击“T”文字工具后，双击区域文字框即可直接编辑；编辑时会显示闪烁输入光标，按 Enter 换行，按 Esc 或点击框外完成编辑。
4. 中文和英文会分别保留各自的字体与字重；编辑、换行和缩放不会把中文细体自动变成粗体。
5. 拖动边框上的 8 个控制点可改变区域文字框大小；拖动顶部圆形手柄可旋转整个文字框。
6. 双击任意一个边框控制点，文字框会自动收紧到当前可见文字的最小边界。
7. 点击“拆分文字块”可把区域文字重新拆回可独立编辑的文字对象。
8. 区域文字支持参考线吸附和画布对齐，旋转状态下同样有效。

六、字体与文字样式
1. 默认英文字体为 Inter，默认中文字体为 Noto Sans SC；英文和中文可分别选择字体及字重。
2. 点击“上传英文字体”或“上传中文字体”可导入自己的字体文件，建议同时准备需要使用的字重。
3. 字号最小可设置为 7 px；可以使用滑杆，也可以直接在右侧数值框输入精确数值。
4. Text Color 可设置文字颜色，也可使用黑/白、推荐色或随机颜色。
5. 可分别开启文字阴影、文字描边和文字背景，并调整颜色、透明度、大小、羽化、描边宽度及圆角等参数。
6. 双击滑杆的黄色圆形按钮，可将对应参数恢复到默认值。
7. 修改某个已选择的文字框时，样式应用到当前文字框；未选择特定对象时，设置将作为当前排版样式使用。

七、图片与背景图层
1. 点击“添加图片”可一次导入一张或多张普通图片；点击“设置背景”可设置主背景图。
2. 普通图片和背景图会统一显示在 Image 图像图层列表中。背景图带有“BG”标记。
3. 点击图层行或画板中的图片即可选中；按住 Shift、Ctrl 或 Command 可多选普通图片图层。
4. 图层列表中的眼睛图标表示显示；带斜线的眼睛表示隐藏。锁图标用于锁定或解锁图层。
5. 背景图默认锁定，防止排字时误操作。需要编辑背景时，可点击图层列表中的锁，或点击画板旁的解锁提示。
6. 直接拖动图片可移动位置；滚动鼠标滚轮可缩放选中的图片。
7. 拖动图片四角可缩放，缩放时对角点保持固定；拖动顶部圆形手柄可旋转。
8. 图片控制面板可调整缩放、旋转、透明度和明暗，并可将图片对齐到画布左侧、中心、右侧、顶部、垂直中心或底部。
9. “替换”会更换图片内容，同时保留当前位置、大小、旋转角度和图层关系，适合排版完成后更换素材。
10. “复制”和“删除”用于复制或移除所选图片。“更多”菜单可上移一层、下移一层、移至顶部、移至底部或显示完整图片。
11. 图层列表支持拖动排序；位于列表上方的普通图片会显示在更高图层。
12. 自动抠图层、背景暗角和重置背景适配属于背景图专属功能。

八、参考线与吸附
1. 在 Grid 网格设置中点击“参考线”，会显示画布参考线，并默认同时打开“吸附”。
2. 吸附开启后，背景图、普通图片和区域文字框都会自动吸附到参考线。
3. 可设置列数、行数、列间隙、行间隙以及左右、上下边距。
4. 如果只想查看参考线而不吸附，可单独关闭“吸附”。

九、透明背景与画面效果
1. 勾选 Transparent 透明背景后，画板会显示灰白棋盘格；棋盘格仅用于提示透明区域，不会出现在导出的透明 PNG 中。
2. JPEG 不支持透明背景，需要透明效果时请选择 PNG 或 SVG。
3. 背景图可使用自动抠图层，让文字形成前后穿插效果；也可开启背景暗角加强画面边缘层次。

十、撤销、重做和快捷键
1. Ctrl/Command + Z：撤销上一步。
2. Ctrl/Command + Shift + Z 或 Ctrl/Command + Y：重做。
3. V：切换到选择工具。
4. T：切换到文字工具。
5. Delete 或 Backspace：删除当前选中的文字或图片。
6. Ctrl/Command + G：组合所选文字对象或文字框。
7. Ctrl/Command + Shift + G：取消组合。
8. Ctrl/Command + 鼠标滚轮：缩放画板查看倍率。
9. 在输入框或文字编辑状态中，常用按键会优先用于输入，不会误触画板快捷操作。

十一、导出建议
1. PNG：适合保留透明背景或需要较高画质的图片。
2. JPEG：适合不需要透明背景、希望文件体积较小的图片。
3. SVG：适合继续编辑或需要矢量输出的场景；复杂图片仍会以图像内容嵌入。
4. SCALE 可选择 1x、2x、3x。倍率越高，输出像素越大，对电脑内存和浏览器性能要求也越高。
5. A3、A4 打印尺寸已经按 300 PPI 提供，通常建议直接使用 1x 输出。
6. 导出前请检查：文字是否完整、图片是否显示、图层顺序是否正确、字体是否已加载、透明背景设置是否符合需要。

十二、常见问题
1. 背景图无法拖动：背景处于锁定状态，请在图层列表或画板解锁提示中解锁。
2. 点击画板总是选到错误图片：先检查图层顺序、显示状态和锁定状态，也可直接在图层列表中选择目标图片。
3. 排版完成后想换图：选中对应图片，点击“替换”，原有位置和大小会保留。
4. 看不到完整画板：点击底部“适合”，或使用“−”缩小画板。不要通过浏览器页面缩放来代替画板缩放。
5. 区域文字框留白过多：双击任意边框控制点，让边框自动贴合文字。
6. 文字无法移动或修改：检查文字锁是否开启，并确认当前使用的是“↖”选择工具还是“T”文字工具。
7. 在其他电脑上字体丢失：请发送完整工具文件夹，不要只发送 HTML 文件。

推荐工作流程
1. 设置背景图，再添加需要的普通图片。
2. 输入文字，分别选择中英文字体、字重及文字样式。
3. 使用默认排版和九宫格确定整体构图。
4. 切换到“↖”选择工具，精细调整自由文字、区域文字和图片图层。
5. 需要整段编辑时，将文字构建为区域文字框；需要单独控制时再拆分文字块。
6. 打开参考线与吸附，完成边缘和中心对齐。
7. 通过底部尺寸菜单切换目标比例，使用“适合”检查完整画板。
8. 检查图层、字体、透明背景和输出尺寸后，再导出最终文件。
